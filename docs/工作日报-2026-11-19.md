## 二、完成事项

### 1. 日报模块与领导查阅页（上午）
- 员工端日报化：去掉周报/月报 Tab，保留 800 字日报正文，支持复制昨天、补写昨天、2 小时内撤回。
- 附件上传改为真实文件（拖拽/点击、20MB 校验、格式白名单、缩略图预览、删除）。
- 新建领导端独立查阅页 `#/report-review`：左侧待查阅/已归档列表点选，右侧宽阅读区、两级点评、附件下载；去掉翻页控件与部门筛选，按登录账号决定视角。
- 修复查阅页滚动失效：`<Spin>` 包裹层插入 flex 链导致 `overflow-y` 失效，用 `:global` 给 `.ant-spin-container` 补 `flex:1; min-height:0`。
- 日报权限隔离：最近报告只取当前用户自己的；领导查阅页保持本团队全量。

### 2. xinbo-oa 后端上线 + 前后端真接通
- Go 1.27 + Gin + mongo-driver 后端落地，`/oa/api/v1` 下 healthz / me / checkin / report / workbench 等接口。
- 修复 4 个真实缺陷：空日报入库、归档日报被覆盖、nginx `proxy_pass` 尾斜杠剥掉 `/oa` 前缀导致 404、查阅页空态不切 Tab。
- 修复越权：组长原本能调 `/report/all-for-review` 看到领导队列全文，改为按 view + role 双重校验。
- 交付 4 个测试账号与权限说明文档（验证码登录 666666）。

### 3. 员工与权限管理（管理员页面）

- 踩坑：seed 补默认值顺序反了会把领导全改成普通员工，已按「先补 leader=true，再补其余 false」修正。

### 4. 工作台待办真实化 + 剩余开发清单

### 5. 批次 1：文件服务 + 打卡照片（MinIO）
- 复用 IM MinIO，新建桶 `xinbo-oa`（桶名必须 ≥3 字符），启动自动建桶。
- `POST /files/upload`、`GET /files/:id`、`GET /files/:id/link`；下载用 30 分钟 HMAC 短签名绕开 `<img>` 无 header 的限制，越权 403。
- 日报附件改存真实地址并禁止 blob/他人文件；打卡照片带水印上传后落 `photo_url/photo_file_id`，存不上就拒绝打卡。
- 踩坑：Go 构建漏 `CGO_ENABLED=0 GOOS=linux GOARCH=amd64` 会导致容器 Restarting 且无日志。

### 6. 打卡定位真实化 + 去除模拟数据

- 删除「模拟照片」入口和写死的「深圳总部 / 定位正常」文案，无坐标或无照片一律拒卡。
- 打卡点默认不预设：环境变量留空时只记录坐标、不判范围、不显示公司名；配置了才判 500m。
- 清理历史假数据，Go 单测 3 组距离用例通过。

### 7. 打卡与出勤拆页 + 底部裁切修复
- `#/checkin` 只做打卡；新增 `#/attendance` 做出勤（月度汇总 + 整宽月历 + 当日明细 + 切月），两页互跳。

### 8. 出勤团队视角规划 + 批次 3.2 落地
- 规划输出 `docs/出勤团队视角-规划.md`：四视角矩阵、统计口径 8 条、接口契约、12 条验收用例。
- 新增 `visibleUserIDs(ctx, uid, scope)` 统一权限（mine/team/all，沿 `manager_id` 递归、防环、排除 disabled），日报/考勤/待办/审批共用，越权 403 而非空列表。
- 作息可配：上班 09:05、下班 18:00、宽限 0 分钟、最早 06:30；判定改「当天第几分钟」比较。
- 新接口 `/checkin/team`、`/checkin/team/:user_id`、`/checkin/report?format=csv`；出勤页三档视图「我的出勤 / 团队出勤 / 出勤报表」，领导/HR 多一档全公司。
- 统计口径统一到 `monthStatOf`：应出勤 = 已过完工作日 + 今天已打上班卡；今天未下班单卡为 `in_progress`，不算缺卡。CSV 带 BOM，Excel 可直接打开。
- 17:20 修两个前端缺陷：视图切换无高亮（Antd Segmented 白底叠白工具栏，改实心蓝 `#0b5fd8`）；团队页/报表一直转圈（父组件内联 `onError` 导致子组件 `useEffect` 无限请求，改 `useRef` + `useCallback` + `reqId`）。

### 9. 批次 4：请假 + 补卡（首个按 8 条清单先设计后编码的功能）

## 六、风险与待决策

1. **生产发布是当前最大上线阻断**：本地 dev 全绿，但公网静态包还是旧版，用户访问不到 OA 页面。
2. **考勤规则粒度**：目前只有全局一套（环境变量），部门/个人级覆盖未实现；若要按部门配，需先做部门树。
3. **请假不扣余额**：一期只记天数，年假余额与调休账本留二期。
4. **移动端未适配**：打卡是主战场，PC 目前只读为主，手机端体验需后续单独排期。
5. **节假日日历未接入**：报表 warnings 已由 `leave_not_integrated` 改为 `holiday_calendar_not_integrated`，需明确是否接第三方日历。
