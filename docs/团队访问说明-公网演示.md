## 重要限制：通话没有声音和画面

隧道只转发 HTTP / WebSocket，**WebRTC 的音视频流走 UDP，穿不过隧道**。所以：

- ✅ 通话的信令正常：发起、来电弹窗、接听、挂断、时长计时都能走通
- ❌ 双方听不到声音、看不到画面

要给团队演示真实通话，只有两条路：

1. 把服务部署到有公网 IP 的服务器，开放 UDP 7882 端口（或配 TURN 服务器）；
2. 团队在同一局域网内访问，并放通本机防火墙（当前机器只有 127.0.0.1 可达，需先改 `config/livekit.yaml` 的 `node_ip` 和 `.env` 的 `LIVEKIT_URL` 为局域网 IP）。

## 隧道运维

```bash
cd D:\work\openim\openim-docker-latest

# 查看当前地址
bash scripts/tunnel.sh url

# 停止隧道
bash scripts/tunnel.sh stop

# 重启隧道（地址会变）
TUNNEL_TARGET=http://openim-tunnel-web:80 bash scripts/tunnel.sh start
```

隧道指向的 `openim-tunnel-web` 是专门构建的**源码版前端容器**（含今天的全部改动），与生产 11001 那个旧产物分开，互不影响。

## 安全提醒

- 临时隧道地址任何人拿到都能访问，演示完建议 `bash scripts/tunnel.sh stop` 关掉；
- 不要把管理员密码、密钥等敏感信息通过演示环境传递；
- 正式对外前请完成：关闭开放注册、更换默认密钥、加数据备份。
